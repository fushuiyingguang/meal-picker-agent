# 模块二：智能筛选与摇号模块

对应页面：`pages/2_picker.py`，需求编号 REQ-2xx。

## 功能定位
核心决策模块：在多条件下筛选菜品并随机摇号，给出「今天吃什么」的推荐，并支持一键生成选餐记录。

## 输入数据
- 筛选条件：分类、口味、荤素、价格上限、距离上限、排除项（如「排除近期已选」）。
- 摇号参数：一次摇出数量（默认 1）。
- 模式：预设模式切换（如 随便吃 / 清淡 / 按预算 / 就近）。

## 处理逻辑
1. 读取 `dishes`，应用多条件筛选得到候选集（分类/口味/荤素/价格/距离）。
2. 不重复推荐：调用 `recent_dish_ids(days)` 排除近期已选。
3. 随机摇号：从候选集用 `random.sample` 抽取 N 个（候选不足时给出提示）。
4. 模式切换：预设模式 = 一组预置筛选条件。
5. 生成记录：点「选定」写 `records`（source=draw）。

## 输出结果
- 推荐菜品卡片/列表（可一次多个）。
- 「再摇一次」「选定并记录」操作。
- 空候选集时的友好提示。
