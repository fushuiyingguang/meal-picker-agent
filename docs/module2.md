# 模块二：智能筛选与摇号

对应页面：`pages/2_picker.py`

## 功能定位
决策核心模块：支持五种用餐模式一键预设，并在分类 / 荤素 / 口味 / 预算 / 位置距离等多条件筛选下随机摇号，给出「今天吃什么」的推荐，支持一键生成选餐记录。位置以**中原工学院（郑州龙湖校区，lat=34.626, lng=113.705）**为默认地理中心。

## 输入数据
- 用餐模式（五选一，切换后自动联动下方筛选条件）：
  - 单人简餐：预算 10-25 元、距离 1000 米、口味清淡/咸、荤素不限
  - 朋友小聚：预算 20-60 元、距离 3000 米、荤菜 + 小吃/烧烤
  - 家庭聚餐：预算 30-100 元、距离 5000 米、荤素搭配
  - 公司聚餐：预算 50-150 元、距离 5000 米、中餐/快餐、荤菜为主
  - 社团团建：预算 30-80 元、距离 3000 米、烧烤/小吃、量大管饱
- 我的位置：纬度 / 经度（手动输入，或点「📍 定位到中原工学院」一键回填）。
- 筛选条件：预算区间（元，滑条）、距离（公里，滑条）、分类（多选）、荤素（下拉）、口味（多选）。
- 摇号参数：一次摇出数量（默认 1）。
- 候选菜品来源：菜品库（含 16 条演示数据 + 团队实地采集北苑1楼77条真实菜品数据）。

## 处理逻辑
1. **模式预设**：切换用餐模式时通过 `on_change` 回调同步各筛选控件的值（预算/距离/荤素/分类/口味），并提示「当前模式：X，已为您自动调整筛选条件」。
2. **候选集计算（实时）**：先按分类（可多选）/荤素/口味/预算区间在 `dishes` 表内筛选，再用 Haversine 公式按经纬度计算与用户位置的直线距离，只保留 ≤ 距离滑条值的菜品，按距离升序；每次改动后自动重算并显示候选数量。
3. **随机摇号**：点击「摇一摇」从候选集用 `random.sample` 抽取 N 个；「🔄 一键重摇」排除刚摇出的菜品重新抽一道，无可选时提示「已没有其他选择啦，请放宽筛选条件」。
4. **生成记录**：点「选定并记录」写入 `records`（source=draw）。
5. **条件冲突提示**：候选集为空时提示放宽预算/距离/口味，并提供「♻️ 一键重置筛选条件」按钮（回到「单人简餐」默认模式）。

> 待办：不重复推荐（`recent_dish_ids`）在后续迭代接入摇号。

## 输出结果
- 「当前符合条件：N 道」候选数量 + 候选菜品列表（菜名/分类/荤素/价格/距离）。
- 「摇一摇」/「🔄 一键重摇」结果（菜名 / 分类 / 荤素 / 直线距离 / 价格）。
- 空候选集时的「条件冲突提示」+「♻️ 一键重置筛选条件」。
- 重摇无其他可选时提示「已没有其他选择啦，请放宽筛选条件」。
