# 模块一：菜品库管理模块

对应页面：`pages/1_dishes.py`，需求编号 REQ-1xx。

## 功能定位
三模块的**数据源头**：负责菜品数据录入、分类、增删改查与导入导出，为「智能筛选与摇号」提供候选集。

## 输入数据
- 单条录入：菜名（必填，唯一）、分类（必填）、价格（可选）、口味（可选，多选：辣/麻/清淡/甜/咸/酸）、荤素（荤/素/半荤素）、距离（可选，米）。
- 批量导入：CSV / Excel（列：`name,category,price,taste,meat_type,distance`，`taste` 可用逗号或 `/` 分隔多个口味）。
- 筛选条件：名称关键字、分类、口味、荤素。

## 处理逻辑
1. **新增**：校验菜名非空且唯一（重名拒绝），写入 `dishes`。
2. **分类**：从预设分类选择（中餐/快餐/面食/小吃/西餐/粥品/甜点/烧烤）。
3. **查询**：按名称/分类/口味/荤素组合筛选，返回列表。
4. **修改**：按 id 更新允许的字段。
5. **删除**：二次确认后删除，历史选餐记录保留——`records.dish_id` 置空、`dish_name` 快照保留菜名。
6. **导出**：按当前列表导出 CSV。
7. **演示数据**：空库时自动注入「附近常见美食」预设数据，保证页面开箱可见。

## 输出结果
- 菜品列表表格（`st.dataframe`）。
- 录入/导入/删除操作反馈。
- 导出文件（CSV）。
- 演示数据（首启自动填充）。
