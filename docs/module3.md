# 模块三：记录评价模块

对应页面：`pages/3_records.py`，需求编号 REQ-3xx。

## 功能定位
选餐后的**闭环模块**：查看历史选餐记录、打分评价，支撑「不重复推荐」，并导出历史与简单统计。

## 输入数据
- 选餐记录（来自模块二摇号，或手动新增）。
- 打分（1-5 星）与评价文字。
- 导出格式选择（CSV/JSON）。

## 处理逻辑
1. 列出 `records`（`dish_name` 快照直接显示菜名，已删除菜品也能正常展示）。
2. 打分/评价：更新 `score` 与 `rating_note`。
3. 不重复推荐支撑：提供 `recent_dish_ids` 给模块二。
4. 统计：各分类选择频率、平均分（可选）。
5. 导出：历史记录导出 CSV/JSON。

## 输出结果
- 历史记录表。
- 评分/评价编辑区。
- 统计信息（可选）。
- 导出文件。
