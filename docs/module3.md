# 模块三：记录评价模块

对应页面：`pages/3_records.py`，需求编号 REQ-3xx。

## 功能定位
选餐后的**闭环模块**：查看历史选餐记录、打分评价、填写就餐备忘，支撑「不重复推荐」，并导出历史与简单统计。

## 输入数据
- 选餐记录（来自模块二摇号，或本页手动新增）。
- 打分（1-5 星）与评价文字。
- 就餐备忘/感受（文本，可选）。
- 导出格式选择（CSV/JSON）。

## 处理逻辑
1. 列出 `records`（`dish_name` 快照直接显示菜名，已删除菜品也能正常展示）。
2. 手动新增：从菜品库选择菜品，写入 `records`（source=manual）。
3. 打分/评价：更新 `score` 与 `rating_note`；下拉框默认定位到第一条未评分记录，保存后 `st.rerun()` 自动跳转到下一条未评分，全部评完提示「所有记录已评价完毕」。
4. 就餐备忘：每条记录可填写「📝 就餐备忘/感受」并「保存备忘」，写入 `records.memo`（独立于打分，不干扰评分跳转）；有备忘的记录在历史下方用 `st.info` 信息框突出展示。
5. 不重复推荐支撑：`recent_dish_ids(days=7)` 返回近期已选菜品 id，供模块二排除。
6. 统计：总记录数、已评分数、平均分、近 7 天已选数、各分类选择频率（按 dish_id 反查分类）。
7. 导出：历史记录导出 CSV/JSON（含备忘列）。

## 输出结果
- 历史记录表（含时间/菜名/来源/评分/评价/备忘）。
- 评分/评价编辑区 + 就餐备忘编辑区。
- 统计信息（指标 + 分类频率）。
- 导出文件（CSV / JSON，含备忘列）。
